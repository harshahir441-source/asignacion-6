Introducción al Desarrollo Web

El desarrollo web es el conjunto de procesos técnicos que hacen posible que una web o aplicación exista, funcione correctamente y evolucione. Incluye desde la parte visible que ve el usuario hasta la lógica interna que gestiona datos, formularios, usuarios o integraciones con otros sistemas.

¿Qué es una Página Web?

Una página web es un documento digital que se muestra en un navegador de internet (como Chrome, Safari o Edge) y que combina texto, imágenes, videos y elementos interactivos.

¿Cómo Funcionan?

El funcionamiento de una pagina web esta estrechamente relacionado con una dirección web, cuando escribes en tu navegador por ejemplo; (www.UTP.com), se activa una serie de procesos tecnológicos que permiten mostrar esa página en tu pantalla.

Tipos de Página Web

Hay varios Tipos de sitios y sitios web, cada uno con un objetivo diferente para empresas, creadores y negocios.

  • Páginas web Estáticas
    •

    Muestran el mismo contenido exactamente igual a todos los visitantes. Sus archivos (HTML, CSS y JavaScript) están previamente construidos y el servidor se limita a entregarlos tal cual están.

  • Páginas web Dinámicas
    •

    Generan el contenido en tiempo real utilizando bases de datos y lenguajes de programación del lado del servidor (como PHP, Python, Node.js o Java). Cambian según la hora, la ubicación, el usuario o la interacción.

Diferencia entre una Aplicación web y Página Web

La principal diferencia es que una página web sirve principalmente para mostrar información de forma estática o de lectura (como un documento HTML), mientras que una aplicación web (web app) es un software interactivo que permite al usuario realizar tareas y procesar datos en tiempo real a través del navegador.
